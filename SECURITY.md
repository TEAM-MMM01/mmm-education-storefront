# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| main | Yes |

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Report security concerns privately through GitHub Private Vulnerability Reporting if available for this repository.

If private reporting is unavailable, contact the repository maintainers through the organization’s approved private security channel and include:
- A clear description of the issue.
- Steps to reproduce.
- Affected files, endpoints, or workflows.
- Expected impact.
- Any suggested remediation.

We will acknowledge receipt as quickly as possible, evaluate severity, confirm reproducibility, and coordinate remediation before any public disclosure.

## Scope

This repository includes:
- Public storefront pages.
- Request-intake workflows and related validation.
- Notification-routing utilities.
- Release-gating and validation scripts.

Please include whether the issue affects:
- Public catalog or content pages.
- Intake endpoints or secrets handling.
- GitHub Actions, CodeQL, or deployment workflows.
- Notification delivery integrations.
